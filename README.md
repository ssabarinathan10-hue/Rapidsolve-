## ✨ Features & Highlights

- **Obsidian Glassmorphism Visual Theme**: Premium dark theme with vibrant neon gradients (#8B5CF6, #3B82F6, #06B6D4) and glassmorphic UI elements.
- **Interactive HTML5 Canvas Particles**: Real-time cursor attraction, node particle network, and responsive rendering.
- **Dynamic Modular Architecture**: Cleanly separated JS modules (`navigation`, `particles`, `scroll`, `animations`, `portfolio`, `team`, `contact`, `main`).
- **Interactive Portfolio & Modal System**: Filter projects by AI, Web, Mobile, and Cloud categories with high-res modal previews.
- **Live Counter Metrics**: Scroll-triggered animated stats (Projects Delivered, Satisfaction Rate, Speed Score, Global Reach).
- **Interactive Contact System**: Real-time form input feedback, floating labels, select options, and animated toast notifications.
- **Dedicated 404 Experience**: Standalone interactive 404 error page (`pages/404.html`).
- **SEO & Accessibility Optimized**: Semantic HTML5 markup, structured headings, fast-loading SVG assets, and ARIA attributes.

## 🚀 Getting Started

1. Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
2. No build tools or npm setup required — standard native modern JavaScript (ES Modules), HTML5, and CSS3.
3. For local development with live reloading, you can serve the directory using VS Code Live Server or python standard server:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`.
